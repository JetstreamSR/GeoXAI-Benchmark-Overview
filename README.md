# GeoXAI Benchmark

**A Case-Grounded Benchmark for Evaluating LLM-Based GeoXAI Agents**

**Author:** Yi Zhao  
**Institution:** Technical University of Munich — Chair of Cartography and Visual Analytics  
**Master's thesis grade:** 1.3 (sehr gut / very good)

## Overview

This master's thesis develops a case-grounded benchmark for evaluating large language model (LLM)-based agents in geospatial explainable AI (GeoXAI).

The project examines how agents interpret and use geospatial explainability evidence, and how their performance compares with LLM-only baselines.

## Main Contributions

- **Evaluation framework:** Designed a framework for evaluating LLM-based GeoXAI agents across different analytical tasks and evidence requirements.
- **Benchmark and automated workflow:** Developed a benchmark containing **509 questions across 26 cases** in the thesis version, supported by an automated workflow and a web platform.
- **Agent evaluation:** Quantified the performance gains of the evaluated GeoXAI agent configurations over LLM-only baselines and analysed their remaining errors.
